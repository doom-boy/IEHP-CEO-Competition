# Supplementary competition materials

These materials provide the IEHP CEO Business Challenge context for the datasets in `data/`.

- `info-session-october-2026.pdf` — October 2026 challenge information session.
- `iehp-case-october-2026.pdf` — IEHP case brief for the challenge.
- `student-guide-access-to-care-analysis.pdf` — student guide for access-to-care analysis.
- `student-guide-financial-impacts-modeling.xlsx` — student guide and workbook for financial-impact modeling.

Use the case brief and guides to understand the competition prompt and analysis expectations; use the source data files in `data/` for quantitative work.
